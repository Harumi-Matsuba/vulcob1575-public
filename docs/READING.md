# Colbert 398 の未解読だった暗号部分の読み

英語版：READING.en.md（表は同じ）

各表は、写本の行ごとに、裁定後の書き起こしに鍵を当てた出力（`data/transcription/<頁>.txt` → `data/decoded/<頁>.txt`）と、語に区切った読みを示す。
鍵の出力では、大文字＝書き起こしで不確かと印を付けた記号、`[..]`＝二重字や符号（`[que]`＝plus、`[est]`＝ucl、`[pour]`＝ros）、`{..}`＝平文の文字の語（符号語か空字）、`·`＝読めない記号。

読みの欄の印：
- ◎ 鍵の出力がそのまま語として読める
- ○ 記号1〜2個を文脈で直した（主に ∂/δ＝i/n、9/q＝d/l、oc/4＝o/a）。出力の欄を見れば分かる
- △ 推定が大きい、読めない記号がある、文の形が分からない
- [..] 符号語。意味は、文脈か解読済みの書簡で支えられるときだけ添えた（OPEN.md）

綴りは鍵のまま（鍵に j と v がないので u/v、i/j はそのまま）。アクセントと句読点は読むのに要るところだけ足した。表の中の注記は英語版と同じ英語のまま。
