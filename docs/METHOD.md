# 方法・数字・AI の使用・限界

英語版：METHOD.en.md（内容は同じ）

## 資料
- BnF, Cinq Cents de Colbert 398（Gallica ark:/12148/btv1b525218133）。シャルル9世・アンリ3世・カトリーヌ・ド・メディシス宛の、ドイツ関係の書簡の原本の綴り。皇帝の宮廷に駐在したフランスの大使 Jean de Vulcob（1575–76年）と Guillaume Ancel（1576–78年・1584年）の書簡を含む。頁は写本の頁付け、f は Gallica のコマ番号（対応は SOURCES.md）。
- 鍵：友清理士氏の復元「Vulcob and Ancel's Cipher (1575-1584)」（Cryptiana `code/frencheastern.htm`、画像 `easternVulcob.png`、ページの Last-Modified 2026-03-15）。同氏は書簡の頁を挙げ、この鍵で未解読の書簡が読めると書いているが、読みは載せていない。
- 画像：BnF の IIIF（幅2400px）。画像はこのリポジトリに入れていない。

## どこが未解読だったか
友清氏の挙げた頁を全部見た。多くの書簡には、左の余白に当時の解読がある。p.525–526、p.539、p.561–563、p.565 の暗号と、p.570 の1行には、それがない。これが未解読だった部分（暗号124行、最終の書き起こしで記号4,383個。ほかに p.524 末の暗号の切れ端）。読みを載せるのは p.525–565（123行、記号4,357個）。

## 手順
1. **鍵の表**（`data/key.tsv`、`src/vk.py` の `TOKENS`）：友清氏の記号に名前を付けた。足したものは `TOKENS` に `C`、残りは友清氏の表（`T`）。表にない記号は OPEN.md の1節。
2. **1回目の書き起こし**（`data/transcription/<頁>_first.txt`）：p.33 と p.539 は Claude Opus 5.5、ほかは Claude Sonnet 5.5 が、拡大した切り出しから記号名で、写本の行ごとに書いた。
3. **照合用の書き起こし**（`second/<頁>_pass1.txt`）：OpenAI の Codex CLI（codex-cli 0.163.0-alpha.10.2、既定のモデル。実行記録にモデル名は出ない）。頁ごとに1回、`codex exec --ephemeral -s read-only` を空のフォルダから。渡したのは行画像（`src/lines.py` で切った。1枚ごとに `-i`）と `second/PROMPT.md`（記号の名前と形の説明だけ。値・鍵・1回目の読みは渡さない）を標準入力で。実行記録は返答1件だけで、コマンドの実行はない（`second/p525_pass1_misaligned.txt` は、p.525 の行画像が2行ずれていた最初の回。やり直したので記録として残すだけ）。
4. **画像での裁定（1回目）**（`xcheck/adjudication_img_<頁>.tsv`、指示は `xcheck/ADJUDICATE_PROMPT.md`）：2 と 3 の食い違いを、Claude Sonnet 5.5 が拡大した画像で見て、画像がはっきり他方を示すときだけ直した。決められないときは1回目のままにして「?」を付けた。結果は `data/transcription/intermediate/<頁>.txt`。
   - 画像での変更が語にならない形で系統的に外れた3種（p→φ の「mait・maire」、3→ʒ の「serblable・directerent」、qa→al の「auon」）は、Claude Opus 5.5 が1回目に戻して「?」を付けた（p.525 で11記号、p.526 で3、p.561 で1）。この15記号は文脈による判断なので、未確定として数える。
   - 表の行数（1回目を残した／2回目を採った／未確定）：p.33 38（18／2／18）、p.525 115（46／59〔うち11は文脈で戻した〕／10）、p.526 89・書式だけ9（25／16〔＋混合5〕／34）、p.539 36・書式だけ5（12／1〔＋混合2〕／16）、p.561 96（54／16／26）、p.562 43（35／5／3）、p.563 93（49／5／39）、p.565 103（63／12／28）、p.570 5（1／0／4）。
5. **Codex の追加の読みと、画像での裁定（2回目）**：Codex に同じ行画像を、こちらの書き起こしを見せずに、`second/PROMPT.md` で1回（pass 2）、`second/PROMPT2.md`（似た形の説明を正確にしたもの）で3回（pass 3a–c）読ませた。途中の書き起こしと pass 3a–c の値の多数決（`src/vote.py`）の食い違いを、Claude Sonnet 5.5 が画像で裁定した（`xcheck/adjudication2_img_<頁>.tsv`、指示 `xcheck/ADJUDICATE_PROMPT2.md`）。採った変更：p.33 2、p.525 6、p.526 7、p.539 3、p.561 5、p.562 1、p.563 10、p.565 6、p.570 1。残りはそのままか「?」。「gn」と書かれた箱の上の十字の記号2つは、鍵の mm（dq）にあたるので dq に名前を替え「?」を付けた（文脈「comme」）。結果が最終の書き起こし `data/transcription/<頁>.txt`。pass 2・3 は直すのに使ったので、独立とは呼ばない。
   - このとき、それまでの行画像が横幅の94%までで、行末の1〜3記号が切れていた（特に p.526）ことが分かった。同じ行の位置で、横幅の99%まで切り直した（`src/recut.py`）。
6. **独立の2回目**（`second/<頁>_pass4[abc].txt`）：最終の書き起こしを決めた後、それを見せずに、切り直した行画像を Codex に新しい文脈で3回読ませた。指示は `second/PROMPT3.md`（PROMPT2 に、8 と 4、箱の上の十字、行末の記号の説明を足したもの。値・鍵・読みは含めない）。実行記録は各回返答1件だけで、コマンドの実行はない。判定には3回のうち最も低い回を使う。
7. **読み**：`src/vk.py decode` で鍵を当て（`data/decoded/`）、語の区切りは Claude Opus 5.5（`docs/READING*.md`）。
8. **対照**：鍵の文字の値を文字の記号のあいだで1,000回かき混ぜ、本物の鍵と、仏語の文字3連のモデル（wordfreq の上位5万語、j→i、v→u）で比べた（`src/vk.py control`）。
9. **較正**：結果を見る前に決めた2頁、余白に当時の解読がある p.258 と p.285（Vulcob、1576年）を、余白を見せずに、未解読の頁とまったく同じ手順で処理した。余白を外した行画像 → Claude Sonnet 5.5 の1回目（`calib/p258_first.txt`・`calib/p285_first.txt`）→ Codex 3回の多数決との食い違いを画像で裁定（`calib/p258.txt`・`calib/p285.txt`）→ 鍵（`calib/p258_decode.tsv`・`calib/p285_decode.tsv`）。余白は Claude Sonnet 5.5 と Codex が別々に書き起こし、食い違いを画像で裁定した（`calib/p258_margin_adj.txt`・`calib/p285_margin_adj.txt`、記録付き）。解読と裁定した余白を文字ごとに比べた（`src/calib.py`）。2頁を合わせて判定する。

**対照**（`xcheck/control.tsv`、各1,000回）：読んだ7頁と p.33 は、全記号でも友清氏の表の記号だけでも 0/1,000。p.570（1行・22記号）は 4/1,000（表の記号だけで 8/1,000）で、0/1,000 に届かないので読みを載せない（READING、OPEN.md の4節）。頁ごとの点は英語版の表。

**較正**（文字だけ。4文字以上の長い食い違い〔符号語の位置や余白の範囲の外〕は数えない）
| 頁 | 比べた文字 | 一致 |
|---|---|---|
| p.258 | 412 | 333（80.8%） |
| p.285 | 148 | 125（84.5%） |
| **2頁** | 560 | **458（81.8%）** |

p.258 の解読を余白の別の読みと比べると 82.1%（Sonnet）・85.8%（Codex）で、答えの側にも揺れがある。p.285 の余白は薄く、18行のうち13行に不確かな語が残る。数えない文字が多いのは、余白が書き出す語が、暗号では平文の文字の符号語だから。記録として：Codex の1回目だけを鍵で読み、p.33 の余白（Claude Opus 5.5 の読み）と比べると 85.5%（234字）。

**値の付いた割合**（最終の書き起こし、9頁）：記号と平文の語 4,672 個のうち、値の付いた記号 4,552（97.4%）、読めない記号 18（0.4%）、平文の文字の語 102（2.2%。多くは意味が分からない）。

**状態：部分的な読み。** 読んだ7頁（p.525–526・539・561–565）で、対照は全頁 0/1,000、独立の2回目の最低は 88.8%（p.565）、7頁で 95.2%、較正は2頁で 81.8%。較正が 85% に届かず、符号語の多くが分からないので、「全文の読み」とは名乗らない。p.570（1行）は読まない。

## AI の使用（COPE の開示）
- Claude Opus 5.5（Anthropic）：先行の調査、鍵の表、p.33 と p.539 の1回目、作業の取りまとめ、鍵の適用、読みの語の区切り、文脈で戻した15記号と名前を替えた2記号、文書。
- Claude Sonnet 5.5（Anthropic）：p.525–526・561–565・570 と較正の p.258・p.285 の1回目、すべての食い違いの画像での裁定（2回）、p.258・p.285 の余白の書き起こしと裁定、解読済みの書簡での符号語の引き当て（ほとんど成果なし）。
- OpenAI Codex CLI 0.163.0-alpha.10.2（既定のモデル）：照合用の書き起こし（pass 1）、直すのに使った追加の読み（pass 2、pass 3a–c）、独立の2回目（pass 4a–c）、p.258・p.285 の余白の書き起こし。
- 解読に加わっていない別の読み手（Claude）が、先行を探した（docs/PRIOR_CHECK.md）。
- **人は、書き起こし・裁定・読みを写本と照らして確かめていない。** AI どうしの一致は、人の確認の代わりにならない。

## 限界
- 似た形の記号の組（OPEN.md の2節）は、一部を文脈で決めている。鍵の出力の大文字が、その不確かな記号。
- 符号語の多くは意味が分からない（OPEN.md の3節）。読みでは [ ] に入れた。
- 較正は2頁だけで、余白の読みも AI による。
- p.570 は1行（採点22記号）だけで、対照を通らないので読まない。
