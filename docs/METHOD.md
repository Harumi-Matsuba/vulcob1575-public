# 方法・数字・AI の使用・限界

英語版：METHOD.en.md（内容は同じ）

## 資料
- BnF, Cinq Cents de Colbert 398（Gallica ark:/12148/btv1b525218133）。シャルル9世・アンリ3世・カトリーヌ・ド・メディシス宛の、ドイツ関係の書簡の原本の綴り。皇帝の宮廷に駐在したフランスの大使 Jean de Vulcob（1575–76年）と Guillaume Ancel（1576–78年・1584年）の書簡を含む。頁は写本の頁付け、f はGallica のコマ番号（頁とコマの対応は SOURCES.md）。
- 鍵：友清理士（S. Tomokiyo）の復元「Vulcob and Ancel's Cipher (1575-1584)」（Cryptiana `code/frencheastern.htm`、画像 `easternVulcob.png`、ページの Last-Modified 2026-03-15）。友清氏は書簡の頁を挙げ、この鍵で未解読の書簡が読めると書いているが、読みは載せていない。
- 画像は BnF の IIIF（幅2400px）で見て切り出した。画像はこのリポジトリに入れていない。

## どこが未解読だったか
友清氏の挙げた頁を全部見た。多くの書簡には、左の余白に当時の解読が書き込まれている。p.525–526、p.539、p.561–563、p.565 の暗号と、p.570 の1行には、それがない。ここで読んだのはこの部分（暗号125行、最終の書き起こしで記号4,377個）。

## 手順
1. **鍵の表**（`data/key.tsv`、`src/vk.py` の `TOKENS`）：友清氏の記号に名前を付けた。足したものは `TOKENS` に印がある（`C`＝較正の頁から、`T`＝友清氏の表）。表にない記号は OPEN.md §1。
2. **1回目の書き起こし**（`data/transcription/<頁>_first.txt`）：p.33 と p.539 は Claude Opus、ほかは Claude Sonnet が、拡大した切り出しから記号名で書いた。
3. **照合用の2回目**（`second/<頁>_pass1.txt`）：OpenAI の Codex CLI（codex-cli 0.163.0-alpha.10.2、既定のモデル。実行記録にモデル名は出ない）。頁ごとに1回、`codex exec --ephemeral -s read-only` を空のフォルダから。渡したのは行画像（`src/lines.py` で切った）と `second/PROMPT.md`（記号の名前と形の説明だけ。値・鍵・1回目の読みは渡さない）。実行記録は返答1件だけで、コマンドの実行やファイルの読み込みはない（`second/p525_pass1_misaligned.txt` は、p.525 の行画像が2行ずれていた最初の回の出力。やり直したので、記録として残すだけ）。
4. **画像での裁定**（`xcheck/adjudication_img_<頁>.tsv`、指示は `xcheck/ADJUDICATE_PROMPT.md`）：2 と 3 の食い違いを、Claude Sonnet が拡大した画像で見て、画像がはっきり他方を示すときだけ直した。決められないときは1回目のままにして「?」を付けた。結果が最終の書き起こし `data/transcription/<頁>.txt`。
   - 画像での変更が、語にならない形で系統的に外れた箇所（p→φ の「mait・maire」、3→ʒ の「serblable」、qa→al の「auon」）は、主セッション（Claude Opus）が1回目に戻して「?」を付けた（p.525 で11記号、p.526 で3、p.561 で1）。これは画像ではなく文脈による判断なので、未確定として扱う。
   - 裁定した食い違いの数（TSV の行数。1行が複数の記号にまたがることがある）は、英語版の表と同じ：p.33 38（1回目18・2回目2・未確定18）、p.525 115（46・59〔うち11は文脈で戻した〕・10）、p.526 89（書式だけ9、25・16〔＋混合5〕・34）、p.539 36（書式だけ5、12・1〔＋混合2〕・16）、p.561 96（54・16・26）、p.562 43（35・5・3）、p.563 93（49・5・39）、p.565 103（63・12・28）、p.570 5（1・0・4）。
5. **独立の2回目**（`second/<頁>_pass2.txt`）：最終の書き起こしを決めた後、Codex を新しい文脈で、同じ指示と行画像でもう一度走らせた。3 は1回目を直すのに使ったので「独立」とは呼ばず、こちらを独立の2回目とする。
6. **読み**：`src/vk.py decode` で鍵を当て（`data/decoded/`）、語の区切りは Claude Opus が付けた（`docs/READING*.md`）。
7. **対照**：鍵の文字の値を、文字の記号のあいだで1,000回かき混ぜ、本物の鍵と、仏語の文字3連のモデル（wordfreq の上位5万語、j→i、v→u）で比べた（`src/vk.py control`）。
8. **較正**：当時の解読がある2頁（p.33・p.258）を、Codex に余白を外した行画像だけで読ませ、鍵を当てて、余白の当時の解読と文字ごとに比べた（`src/calib.py`）。p.258 の余白は Claude Sonnet が暗号を見ずに書き起こし、p.33 の余白は Claude Opus が読んだ。

## 数字
**独立の2回目との一致率**（記号を値に直して行ごとに対応、`src/xcompare.py`）

| p.33 | p.525 | p.526 | p.539 | p.561 | p.562 | p.563 | p.565 | p.570 | 合計 |
|---|---|---|---|---|---|---|---|---|---|
| 93.8% | 86.3% | 84.6% | 85.9% | 81.5% | 87.3% | 87.3% | 91.7% | 73.1% | **4,017/4,637＝86.6%** |

- 名前どおりに数えると 3,996/4,661＝85.7%（Codex は同じ形に別の名前を付けることが多い。例：oc を fl）。
- 比べるための目安：Codex の1回目と2回目（同じモデルが同じ画像を2回）90.9%、裁定前の1回目と Codex の1回目 86.7%、裁定前の1回目と Codex の2回目 84.9%。食い違いの多くは似た形の組（OPEN.md §2）。

**対照**（`xcheck/control_v2.tsv`、各1,000回）：全頁で本物以上 0/1,000。「友清氏の表の記号だけ」の条件でも、p.570（1行・23記号）の1/1,000 を除き 0/1,000。Codex の書き起こしにそのまま鍵を当てても全頁で 0/1,000。各頁の点は英語版の表。

**較正**（Codex の書き起こし→鍵→余白の当時の解読と文字ごと。4文字以上の長い食い違い〔符号語の位置や余白の範囲の外〕は数えない）
| 頁 | 比べた文字 | 一致 | 数えなかった文字 |
|---|---|---|---|
| p.33 | 234 | 200（85.5%） | 72 |
| p.258 | 389 | 319（82.0%、d と l を同じとみると 83.5%） | 461 |

余白の文字全体に対して数えると（4文字以上の一致の連なり）、p.258 の余白の 42% にとどまる。差の多くは符号語（余白が「l'Electeur palatin」「les autres electeurs」などと書く所が、暗号では平文の文字の語）と、Codex が 9 を q と読む癖（d→l）による。

**値の付いた割合**：最終の書き起こしの記号と平文の語 4,667 個のうち、値の付いた記号 4,551（97.5%）、読めない記号 20（0.4%）、平文の文字の語（符号語・空字）96（2.1%。多くは意味が分からない）。

**段階（このシリーズで使っている閾値）**：B「部分的な読み」。対照は全頁 0/1,000、独立の2回目は全頁 70% 以上（最低は p.570 の 73.1%）、較正 65% 以上。C「全文の読み」には届かない（独立の2回目が p.526・p.561・p.570 で 85% 未満、p.258 の較正が文字 82.0%）。

## AI の使用（COPE の開示）
- Claude Opus 5.5（主セッション、Claude Code）：先行の調査、鍵の表、p.33 と p.539 の1回目、作業の取りまとめ、鍵の適用、読みの語の区切り、文書。画像での裁定の変更のうち15記号を文脈で戻した（「?」付き）。
- Claude Sonnet 5.5（サブエージェント）：p.525–526・561–565・570 の1回目、食い違いの画像での裁定、p.258 の余白の書き起こし、解読済みの書簡での符号語の引き当て（ほとんど成果なし）。
- OpenAI Codex CLI 0.163.0-alpha.10.2（既定のモデル）：2回目の書き起こし（1回目は裁定に使用、2回目は独立）、p.258 の較正用の書き起こし。
- **人は、書き起こし・裁定・読みを写本と照らして確かめていない。** AI どうしの一致は、人の確認の代わりにならない。

## 限界
- 似た形の記号の組（OPEN.md §2）は、一部を文脈で決めている。鍵の出力の大文字が、その不確かな記号。
- 符号語の多くは意味が分からない（OPEN.md §3）。読みでは [ ] に入れた。
- 較正は2頁だけで、余白の書き起こしも AI による。
- p.570 は1行（23記号）だけで、対照の結果は弱い。
