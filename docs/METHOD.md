# 方法・数字・AI の使用・限界

英語版：METHOD.en.md（内容は同じ）

## 資料
- BnF, Cinq Cents de Colbert 398（Gallica ark:/12148/btv1b525218133）。シャルル9世・アンリ3世・カトリーヌ・ド・メディシス宛の、ドイツ関係の書簡の原本の綴り。皇帝の宮廷に駐在したフランスの大使 Jean de Vulcob（1575–76年）と Guillaume Ancel（1576–78年・1584年）の書簡を含む。頁は写本の頁付け、f は Gallica のコマ番号（対応は SOURCES.md）。
- 鍵：友清理士氏の復元「Vulcob and Ancel's Cipher (1575-1584)」（Cryptiana `code/frencheastern.htm`、画像 `easternVulcob.png`、ページの Last-Modified 2026-03-15）。同氏は書簡の頁を挙げ、この鍵で未解読の書簡が読めると書いているが、読みは載せていない。
- 画像：BnF の IIIF（幅2400px）。画像はこのリポジトリに入れていない。

## どこが未解読だったか
友清氏の挙げた頁を全部見た。多くの書簡には、左の余白に当時の解読がある。p.525–526、p.539、p.561–563、p.565 の暗号と、p.570 の1行には、それがない。ここで読んだのはこの部分（暗号125行、最終の書き起こしで記号4,377個）。

## 手順
1. **鍵の表**（`data/key.tsv`、`src/vk.py` の `TOKENS`）：友清氏の記号に名前を付けた。足したものは `TOKENS` に `C`、残りは友清氏の表（`T`）。表にない記号は OPEN.md の1節。
2. **1回目の書き起こし**（`data/transcription/<頁>_first.txt`）：p.33 と p.539 は Claude Opus 5.5、ほかは Claude Sonnet 5.5 が、拡大した切り出しから記号名で、写本の行ごとに書いた。
3. **照合用の書き起こし**（`second/<頁>_pass1.txt`）：OpenAI の Codex CLI（codex-cli 0.163.0-alpha.10.2、既定のモデル。実行記録にモデル名は出ない）。頁ごとに1回、`codex exec --ephemeral -s read-only` を空のフォルダから。渡したのは行画像（`src/lines.py` で切った。1枚ごとに `-i`）と `second/PROMPT.md`（記号の名前と形の説明だけ。値・鍵・1回目の読みは渡さない）を標準入力で。実行記録は返答1件だけで、コマンドの実行はない（`second/p525_pass1_misaligned.txt` は、p.525 の行画像が2行ずれていた最初の回。やり直したので記録として残すだけ）。
4. **画像での裁定**（`xcheck/adjudication_img_<頁>.tsv`、指示は `xcheck/ADJUDICATE_PROMPT.md`）：2 と 3 の食い違いを、Claude Sonnet 5.5 が拡大した画像で見て、画像がはっきり他方を示すときだけ直した。決められないときは1回目のままにして「?」を付けた。結果が最終の書き起こし `data/transcription/<頁>.txt`。
   - 画像での変更が語にならない形で系統的に外れた3種（p→φ の「mait・maire」、3→ʒ の「serblable・directerent」、qa→al の「auon」）は、Claude Opus 5.5 が1回目に戻して「?」を付けた（p.525 で11記号、p.526 で3、p.561 で1）。この15記号は画像でなく文脈による判断なので、未確定として数える。
   - 裁定の表の行数（1行が複数の記号にまたがることがある。1回目を残した／2回目を採った／未確定）：p.33 38（18／2／18）、p.525 115（46／59〔うち11はのちに文脈で戻した〕／10）、p.526 89・書式だけ9（25／16〔＋混合5〕／34）、p.539 36・書式だけ5（12／1〔＋混合2〕／16）、p.561 96（54／16／26）、p.562 43（35／5／3）、p.563 93（49／5／39）、p.565 103（63／12／28）、p.570 5（1／0／4）。
5. **独立の2回目**（最終の書き起こしを決めた後に、それを見せずに）：Codex を、毎回新しい文脈で、同じ行画像で走らせた。
   - pass 2（`second/<頁>_pass2.txt`）：指示 `second/PROMPT.md`、1回。
   - pass 3a・3b・3c（`second/<頁>_pass3[abc].txt`）：指示 `second/PROMPT2.md`。裁定で分かった似た形（9/q、∂/δ、十字形の記号、大きな弧の S、qa/al、L/g）の説明を正確にしたもの（値・鍵・読みは含めない）。3回を別々に。`src/vote.py` で、こちらの書き起こしを使わずに3回の値の多数決を作った（`second/<頁>_pass3vote.txt`、参考）。
6. **読み**：`src/vk.py decode` で鍵を当て（`data/decoded/`）、語の区切りは Claude Opus 5.5（`docs/READING*.md`）。
7. **対照**：鍵の文字の値を文字の記号のあいだで1,000回かき混ぜ、本物の鍵と、仏語の文字3連のモデル（wordfreq の上位5万語、j→i、v→u）で比べた（`src/vk.py control`）。
8. **較正**：余白に当時の解読がある p.258 を、余白を見せずに、未解読の頁とまったく同じ手順で処理した。余白を外した行画像 → Claude Sonnet 5.5 の1回目（`calib/p258_first.txt`）→ Codex 3回の多数決との食い違いを画像で裁定（`calib/p258.txt`、`xcheck/adjudication_img_p258.tsv`）→ 鍵（`calib/p258_decode.tsv`）。余白は Claude Sonnet 5.5 と Codex が別々に書き起こし、食い違いを画像で裁定した（`calib/p258_margin_adj.txt`、記録 `calib/p258_margin_adj_log.tsv`）。解読と裁定した余白を文字ごとに比べた（`src/calib.py`）。

**対照**（`xcheck/control.tsv`、各1,000回）：全頁で本物以上 0/1,000。「友清氏の表の記号だけ」の条件でも、p.570（1行・23記号）の1/1,000 を除き 0/1,000。Codex の書き起こし（pass 1）にそのまま鍵を当てても、p.33 と p.525–565 で 0/1,000。頁ごとの点は英語版の表。

**較正**（文字だけ。4文字以上の長い食い違い〔符号語の位置や余白の範囲の外〕は数えない）
| 比べたもの | 比べた文字 | 一致 |
|---|---|---|
| **p.258、全手順**（裁定後の書き起こし→鍵）と裁定した余白 | 412 | **333（80.8%）** |
| 同じ、d と l を同じとみる | 379 | 309（81.5%） |
| p.258、1回目だけ→鍵と裁定した余白 | 376 | 304（80.9%） |
| p.258、Codex の1回目→鍵と余白（Sonnet の読み） | 389 | 319（82.0%） |
| p.33、Codex の1回目→鍵と余白（Claude Opus 5.5 の読み） | 234 | 200（85.5%） |

判定に使うのは、全手順と裁定した余白の 80.8%。同じ解読を余白の別の読みと比べると 82.1%（Sonnet）・85.8%（Codex）で、答えの側にも揺れがある。数えない文字が多い（p.258 で430字）のは、余白が「l'Electeur palatin」などと書く所が、暗号では平文の文字の符号語だから。

**値の付いた割合**：最終の書き起こしの記号と平文の語 4,667 個のうち、値の付いた記号 4,551（97.5%）、読めない記号 20（0.4%）、平文の文字の語（符号語・空字）96（2.1%。多くは意味が分からない）。

**状態：部分的な読み。** 対照は全頁 0/1,000、独立の2回目は全頁・全回で 73.1% 以上、較正 80.8%。「全文の読み」とは名乗らない。独立の2回目の最低が p.526（84.6%）・p.561（81.5%）・p.570（73.1%、1行）で 85% に届かず、較正も 85% に届かず、符号語の多くが分からないため。

## AI の使用（COPE の開示）
- Claude Opus 5.5（Anthropic）：先行の調査、鍵の表、p.33 と p.539 の1回目、作業の取りまとめ、鍵の適用、読みの語の区切り、文脈で戻した15記号、文書。
- Claude Sonnet 5.5（Anthropic）：p.525–526・561–565・570 と較正の p.258 の1回目、すべての食い違いの画像での裁定、p.258 の余白の書き起こしと裁定、解読済みの書簡での符号語の引き当て（ほとんど成果なし）。
- OpenAI Codex CLI 0.163.0-alpha.10.2（既定のモデル）：照合用の書き起こし（pass 1）、独立の2回目（pass 2、pass 3a–c）、p.258 の余白の書き起こし。
- 解読に加わっていない別の読み手（Claude）が、先行を探した（docs/PRIOR_CHECK.md）。
- **人は、書き起こし・裁定・読みを写本と照らして確かめていない。** AI どうしの一致は、人の確認の代わりにならない。

## 限界
- 似た形の記号の組（OPEN.md の2節）は、一部を文脈で決めている。鍵の出力の大文字が、その不確かな記号。
- 符号語の多くは意味が分からない（OPEN.md の3節）。読みでは [ ] に入れた。
- 較正は1頁だけで、余白の読みも AI による。
- p.570 は1行（採点23記号）だけで、対照の結果は弱い。
